# Data handling
Citizen text and assessment snapshots live in the individual Streamlit session. There is no database or routine raw-text log. Model requests go to the configured HTTP endpoint (localhost by default). Reset discards the application session; it cannot erase a JSON export the citizen saved. Export includes original citizen text, quoted evidence, correction restatements/reasons, validation clarifications and configuration versions. Logs rotate under the ignored `.runtime/` directory; vLLM request-content logging is disabled. In-memory data may remain in process memory until reclaimed; no stronger erasure guarantee is claimed.
